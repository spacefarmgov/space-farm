# Yeni söhbətdə və ya fasilədən sonra davam
İlk cümlədə özünüzə aid A, B və ya C seçin. Branch-ınız məlumdursa agent onu yoxlamalıdır.

## Antigravity-yə yapışdırılacaq mətn

Mənim rolum: A / B / C — burada yalnız mənim faktiki rolumu saxla.
Team CODE44-ün **Space Farm** (`space-farm`) layihəsində əvvəlki işə davam edirik. Yeni layihə yaratma, arxitekturanı yenidən seçmə.

AGENTS.md, TEAM_RULES.md, PROJECT_PLAN.md, PROJECT_STATE.md, ROADMAP.md,
docs/TEAM_PLAYBOOK.md, docs/API_CONTRACT.md və mənim docs/status/frontend.md / backend.md / data.md faylımı oxu.
Cari git branch, status və son commitləri yoxla. Başqasının işini dəyişmə.
Working tree təmizdirsə remote-dan fetch et və docs/GIT_WORKFLOW.md qaydasına görə öz branch-ımı develop ilə sinxronlaşdır. Dirty-dirsə əvvəl dəyişiklikləri müəyyən et və qoru.
B-nin son ortaq state-i köhnədirsə bunu qeyd et; digər kompüterdəki push edilməmiş işi bildiyini fərz etmə.

İlk cavabında:
- Mənim rolum və branch.
- Son tamamlanmış task və sübut.
- Hazırkı blocker və contract version.
- İndi davam edəcəyin bir konkret task.

Sonra həmin task-ı icra et. Kontrakt dəyişikliyi ehtiyacı varsa sahibinə CR ver; bütün işi yenidən yazma.
Uyğun testləri et, öz jurnalını yenilə, owner yollarından kənar diff olmadığını yoxla, işi PR üçün hazırla.
